# Davomat WebApp

Telegram WebApp for employee attendance tracking.

## Features
- Camera capture with face detection frame
- GPS location tracking
- Real-time clock
- iOS-style glassmorphism design
- Responsive mobile interface

## Local Development
```bash
# Open index.html in browser
# For local testing, use with API server from ../Server/API/
```

## Production Deployment
This WebApp can be deployed to:
- Netlify
- Vercel
- GitHub Pages
- Any static hosting service

Set environment variable: `API_URL=https://your-server-domain.com`

## Files
- `index.html` - Main HTML structure
- `style.css` - iOS-style CSS with glassmorphism
- `app.js` - JavaScript logic for camera, GPS, and API calls
